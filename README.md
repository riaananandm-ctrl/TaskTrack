# TaskTrack

**Know what's next.** TaskTrack is a study planner for IB MYP and DP students. It
pulls tasks in from ManageBac, sorts them by subject and priority, reminds you
before deadlines, and helps you study with AI study sessions, a rewrite coach and
practice grading.

Try it: **https://tasktrackbm.vercel.app**
